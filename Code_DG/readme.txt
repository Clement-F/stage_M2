Tu peux créer un dossier ./bin dans ton dossier personnel, dans lequel tu peux copier les fichiers "makeDG", "make_gfortran", "make_gfortran_debug" et "cleanDG. Il faudra peut-être que tu te donnes tous les droits sur ces fichiers avec la commande "chmod". Dans ce dossier "bin", tu pourras aussi y mettre tes propres scripts bash.

Ensuite, pour compiler le programme, mets toi dans le dossier "V2", et tape la commande "makeDG gfortran" (ou makeDG gfortran_debug pour la version debug). La commande "cleanDG" pour nettoyer le dossier "SOURCES"
